VOCABULARY
accepter (ak-sep-TAY) - to accept
refuser (ruh-fyoo-ZAY) - to refuse
proposer (pro-po-ZAY) - to suggest, offer
laisser (leh-SAY) - to let, leave
prêter (pray-TAY) - to lend
emprunter (ahm-prun-TAY) - to borrow
la permission (lah pair-mee-SYOHN) - permission
une invitation (ewn ehn-vee-tah-SYOHN) - an invitation
volontiers (voh-lon-TYAY) - gladly
la demande (lah duh-MAHND) - request

GRAMMAR
Pouvoir for polite requests - Use pouvoir (to be able to/can) followed by an infinitive to ask politely if someone can do something. In everyday French, Tu peux…? is a friendly way to make a request.

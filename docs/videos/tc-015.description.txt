VOCABULARY
Bonjour. (bohn-ZHOOR) - Hello.
Je voudrais envoyer un colis, s'il vous plaît. (zhuh voo-DRAY ahn-vwah-YAY uhn koh-LEE, seel voo PLEH) - I would like to send a package, please.
Où voulez-vous envoyer le colis ? (oo voo-LAY voo ahn-vwah-YAY luh koh-LEE) - Where would you like to send the package?
Vous pouvez poster le colis ici. (voo poo-VAY poh-STAY luh koh-LEE ee-SEE) - You can post the package here.
Combien, s'il vous plaît ? (kohm-BYEHN, seel voo PLEH) - How much, please?

GRAMMAR
Vouloir + infinitive for polite requests - Use vouloir followed by an infinitive to say what someone wants to do. Je voudrais is the conditional form and a polite way to say “I would like”; voulez-vous literally asks “do you want,” and can be used politely as “would you like.”

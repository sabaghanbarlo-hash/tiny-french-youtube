VOCABULARY
le portable (por-TABL) - mobile phone
l’Internet (an-tehr-NET) - Internet
l’écran (ay-KRAHN) - screen
le message (meh-SAHZH) - message
le site (SEET) - website
charger (shar-ZHAY) - to charge
télécharger (tay-lay-shar-ZHAY) - to download
le clavier (klah-VYAY) - keyboard
le chargeur (shar-ZHUR) - charger
le réseau (ray-ZOH) - network

GRAMMAR
Pouvoir + infinitive - To say that someone can do something, use a form of pouvoir followed by an infinitive. The infinitive stays in its basic form.

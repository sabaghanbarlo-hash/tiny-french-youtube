Four ways to ask for the bill in French! - 
This one is very polite. - 
Je voudrais payer, s'il vous plaît. - I would like to pay, please.
This one is normal. - 
L'addition, s'il vous plaît. - The bill, please.
This one is casual. - 
On peut payer ? - Can we pay?
And this one is a bit rude! - 
L'addition ! - The bill!
Which one would you say? Comment 1, 2, 3 or 4! -

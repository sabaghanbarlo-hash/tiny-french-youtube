VOCABULARY
Je voudrais changer la réservation, s'il vous plaît. (zhuh voo-dreh shahn-zhay lah ray-zair-vah-SYOHN, seel voo PLEH) - I’d like to change the reservation, please.
Vous voulez changer la date ? (voo voo-lay shahn-zhay lah DAHT) - Do you want to change the date?
Pour combien de jours ? (poor kohm-BYEN duh zhoor) - For how many days?
La chambre est disponible demain. (lah SHAHMBR eh dee-spoh-NEEBL duh-MAN) - The room is available tomorrow.
C'est parfait. (say par-FAY) - That’s perfect.

GRAMMAR
Polite requests with « je voudrais » - Use « je voudrais » followed by an infinitive to make a polite request. The infinitive names the action you would like to do.

VOCABULARY
réserver une table (ray-zehr-VAY ewn TAH-bluh) - to book a table
pour deux personnes (poor duh pehr-SON) - for two people
pour quand ? (poor KAHN) - for when?
complet / complète (kohn-PLEH / kohn-PLET) - full, fully booked
c'est à quel nom ? (seh ah kel NOHN) - what name is it under?
au nom de … (oh nohn duh) - under the name …
végétarien / végétarienne (vay-zhay-tah-ree-AN / -EN) - vegetarian
bien sûr (bee-AN SEWR) - of course

GRAMMAR
Booking with je voudrais - Use Je voudrais réserver une table pour + number of people. Add the day and time with pour: pour vendredi soir, à vingt heures. If the restaurant is full, expect Nous sommes complets.
Giving your name - French uses au nom de + surname: Au nom de Martin. The server may ask C'est à quel nom ? Spell your name with the French alphabet if needed.
Paying: par and en - Ask for the bill with L'addition, s'il vous plaît. Say how you pay with par carte (by card) or en espèces (in cash). Tipping is not required in France because service is included, but you can leave a few coins.

VOCABULARY
Je voudrais réserver une table pour deux, s'il vous plaît. (zhuh voo-DRAY ray-zer-VAY oon TAHBL poor DUH, seel voo PLEH) - I’d like to reserve a table for two, please.
Quand souhaitez-vous réserver ? (kahn sweh-TAY voo ray-zer-VAY) - When would you like to reserve?
Pour demain soir, à sept heures, s'il vous plaît. (poor duh-MAN swar, ah SET uhr, seel voo PLEH) - For tomorrow evening, at seven, please.
Vous avez une table près de la fenêtre ? (voo zah-VAY oon TAHBL preh duh lah fuh-NETR) - Do you have a table near the window?
Je vous réserve une table près de la fenêtre. (zhuh voo ray-ZEHRV oon TAHBL preh duh lah fuh-NETR) - I’ll reserve you a table near the window.

GRAMMAR
A polite request with « voudrais » - Use « je voudrais » followed by an infinitive to make a polite request. « Voudrais » is a conditional form of vouloir, meaning “would like.”

VOCABULARY
le jeu (ZHUH) - game
un ballon (bah-LOHN) - ball
le football (foot-BOL) - soccer
le tennis (teh-NEES) - tennis
le match (MATCH) - game, match
une équipe (ay-KEEP) - team
gagner (gah-NYAY) - to win
perdre (pair-DRUH) - to lose
courir (koo-REER) - to run
nager (nah-ZHAY) - to swim

GRAMMAR
Vouloir + infinitive - Use vouloir (to want) followed by an infinitive to say what someone wants to do. The infinitive stays unchanged, even when the subject changes.

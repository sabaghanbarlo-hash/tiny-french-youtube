I don't care, in French, from polite to very rude! - 
This one is polite. - 
Peu importe. - It doesn't matter.
This one is casual. - 
Ça m'est égal. - I don't mind.
This one is a bit rude. - 
Je m'en fiche. - I don't care.
And this one is very rude! - 
Je m'en fous ! - I couldn't care less!

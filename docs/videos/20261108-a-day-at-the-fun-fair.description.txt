VOCABULARY
la barbe à papa (la barb a pa-PA) - cotton candy
un manège (uhn ma-NEZH) - a ride / carousel
haut (OH) - high / tall
amusant (a-mu-ZAN) - fun

GRAMMAR
Deux + noun, s'il vous plaît - Use this to ask politely for a number of things
C'est + adjective - Use this to say how something is
